```yaml
      run: npx playwright install --with-deps chromium
    
    - name: Run E2E tests
      run: npm run test:e2e
      env:
        PUBLIC_SUPABASE_URL: http://localhost:54321
        PUBLIC_SUPABASE_ANON_KEY: ${{ secrets.SUPABASE_LOCAL_ANON_KEY }}
    
    # ✅ 上傳測試報告
    - uses: actions/upload-artifact@v3
      if: always()
      with:
        name: test-results
        path: |
          test-results/
          playwright-report/
```

## 最終建議優先順序(針對你的 C2C 電商專案)

| 優先級 | 測試類型 | 工具 | 關鍵測試場景 |
| :-- | :-- | :-- | :-- |
| **🔴 P0** | RLS 政策 | pgTAP | 賣家權限隔離、買家資料保護 |
| **🔴 P0** | 推薦演算法 | pgTAP + 整合測試 | 函數正確性、效能、邊界條件 |
| **🟡 P1** | 認證流程 | Playwright | 註冊、登入、權限切換 |
| **🟡 P1** | 交易流程 | Playwright | 下單、付款、訂單狀態 |
| **🟢 P2** | 元件單元 | Vitest | UI 元件邏輯 |

## 額外推薦工具

考慮加入 [RLS Scope](https://github.com/xaac-ai/rls-scope) - AI 自動生成 RLS 測試案例,幫助你發現遺漏的權限漏洞:[^1_8]

```bash
npx rls-scope  # 自動分析並生成測試
supabase test db --linked
```
