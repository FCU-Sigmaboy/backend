## 🎬 詳細步驟說明

### 1️⃣ 啟動應用

```bash
cd Map_Function/frontend
npm run dev
```

瀏覽器自動開啟 `http://localhost:3000`

## 🔄 後端處理流程

```
前端點擊按鈕
    ↓
navigator.geolocation.getCurrentPosition()
    ↓
取得座標 {lat: 25.0330, lng: 121.5654}
    ↓
呼叫 Edge Function
POST /functions/v1/save-location
Headers: Authorization: Bearer <JWT>
Body: {latitude: 25.0330, longitude: 121.5654}
    ↓
Edge Function 驗證 JWT Token
    ↓
從 Token 取得 user_id
    ↓
建立 PostGIS 地理點
locationPoint = "POINT(121.5654 25.0330)"
    ↓
寫入資料庫
INSERT INTO locations (user_id, coordinates, type, is_primary)
    ↓
RLS 策略檢查
auth.uid() = user_id ✅
    ↓
資料成功儲存
    ↓
回傳成功訊息給前端
    ↓
前端顯示：✅ 位置已成功儲存！
```

## ❌ 常見錯誤處理

### 錯誤 1：無法取得位置
```
❌ 您已拒絕位置授權，請至瀏覽器設定中重新開啟。
```
**解決**：
- Chrome: 設定 > 隱私權和安全性 > 網站設定 > 位置
- 找到 localhost:3000，設為「允許」

### 錯誤 2：未登入
```
❌ 請先登入！
```
**解決**：
- 返回登入畫面並登入

### 錯誤 3：地圖無法載入
```
(地圖區域顯示錯誤)
```
**解決**：
- 檢查 .env 中的 VITE_GOOGLE_MAPS_API_KEY 是否正確
- 確認 Maps JavaScript API 已啟用

### 錯誤 4：儲存失敗
```
❌ 無法儲存您的位置，請稍後再試。
```
**解決**：
- 檢查 Edge Function 是否正在運行
- 檢查 Supabase 連線是否正常
- 查看瀏覽器 Console 的詳細錯誤訊息

## 📊 資料查詢

查詢您儲存的所有位置：

```sql
-- 在 Supabase Studio 的 SQL Editor 執行
SELECT
    id,
    ST_Y(coordinates::geometry) AS latitude,
    ST_X(coordinates::geometry) AS longitude,
    type,
    is_primary,
    formatted_address,
    created_at
FROM public.locations
WHERE user_id = auth.uid()
ORDER BY created_at DESC;
```
